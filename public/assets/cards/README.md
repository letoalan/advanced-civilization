# Répertoire des Assets Graphiques de Cartes

Ce répertoire héberge les illustrations des cartes servies nativement par l'application :

- `commodities/` : Les 18 cartes de marchandises (`ochre.webp`, `iron.webp`, ..., `gold.webp`, `ivory.webp`).
- `calamities/` : Les 12 cartes de calamités (`volcano.webp`, `epidemic.webp`, `piracy.webp`, etc.).
- `advances/` : Les 24 cartes d'avances de civilisation (`pottery.webp`, `astronomy.webp`, `democracy.webp`, etc.).
- `back/` : Les dos de cartes (`commodity-back.webp`, `calamity-back.webp`, `advance-back.webp`).

Les formats recommandés sont le **WebP** ou le **PNG**, au ratio 2:3 (ex: 400 × 600 px).
En l'absence d'une image, les composants de cartes basculent automatiquement sur un repli vectoriel CSS stylisé.
